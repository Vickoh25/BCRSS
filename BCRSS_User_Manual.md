## 1. Introduction

The **Baraton Community Resource Sharing System (BCRSS)** is a web platform designed for neighborhood households, local farmers, traders, and chama groups in Baraton (Nandi County, Kenya) to list, discover, and exchange resources such as farm tools, textbooks, and casual job opportunities.

### What You Can Do

| Feature | Description |
|---------|-------------|
| **Resource Sharing** | List and borrow farm tools, textbooks, household items |
| **Job Board** | Post and apply for casual labor, farm work, tutoring gigs |
| **Borrow Requests** | Request, approve, decline, and track borrow cycles |
| **Reviews & Ratings** | Star ratings and feedback after transactions |
| **Admin Panel** | Platform management, user moderation, and reporting |

### User Roles

| Role | Access Level |
|------|-------------|
| **Admin** | Full platform access: user management, resource moderation, job oversight, analytics reports |
| **Member** | Browse resources and jobs, post listings, submit borrow requests, leave reviews |

## 2. Getting Started

### 2.1 Creating an Account

1. Open the BCRSS website in your browser
2. Select **Sign Up** from the navigation bar
3. Complete the registration form
4. Select **Create Account**

*[Screenshot: Registration Form — Fig. 2.1]*

**Registration Fields:**

| Field | Required | Notes |
|-------|:--------:|-------|
| Full Name | ✓ | Your display name on the platform |
| Email | ✓ | Used for login and notifications |
| Password | ✓ | Minimum 8 characters |
| Location | ✓ | Your area in Baraton (e.g., UEAB Campus, Baraton Market Area) |
| Phone Number | ✓ | For contact during borrow/job transactions |

> **Note:** Your account is created as a **Member** by default. Admin accounts are assigned by existing administrators.

---

### 2.2 Signing In

1. Select **Login** from the navigation bar
2. Enter your **Email** or **Username**
3. Enter your **Password**
4. Select **Login**

*[Screenshot: Login Modal — Fig. 2.2]*

> **Tip:** Your session is remembered on the device. You won't need to log in again unless you clear your browser data.

---

### 2.3 Forgot Password

If you cannot remember your password:

1. Select **Forgot Password?** from the login modal
2. Enter your registered email address
3. Check your email for a password reset link
4. Follow the link to set a new password

*[Screenshot: Forgot Password Modal — Fig. 2.3]*

## 4. Managing Resources

### 4.1 Browsing Resources

Select **Resources** from the main navigation to browse all available items. Use the search bar and filters to find specific items.

*[Screenshot: Resources Page — Fig. 4.1]*

**Filter Options:**

| Filter | Options |
|--------|---------|
| **Search** | Free-text search by title or description |
| **Category** | All, Farm Tools, Textbooks, Household Items, Trade Equipment, Chama Resources |
| **Status** | All, Available, Borrowed |

---

### 4.2 Sharing a Resource

1. Select **Share Resource** from the navigation bar or home page
2. Complete the resource form
3. Select **Submit Listing**

*[Screenshot: Share Resource Modal — Fig. 4.2]*

**Listing Fields:**

| Field | Required | Notes |
|-------|:--------:|-------|
| Title | ✓ | Name of the item |
| Category | ✓ | Farm Tools, Textbooks, Household Items, Trade Equipment, Chama Resources |
| Condition | ✓ | Excellent, Good, or Fair |
| Description | ✓ | Detailed description of the item |
| Lending Type | ✓ | Borrowing or Donation |
| Location | ✓ | Where the item can be picked up |

> **Tip:** Add a detailed description including size, condition details, and any usage instructions. This helps borrowers know exactly what to expect.

---

### 4.3 Borrowing a Resource

1. Browse to the resource you want to borrow
2. Select **Borrow** on the resource card
3. Fill in the borrow request form:
   - **Start Date** — When you need the item
   - **End Date** — When you'll return it
   - **Message** — A note to the owner explaining your need
4. Select **Submit Request**

*[Screenshot: Borrow Request Modal — Fig. 4.3]*

> **Note:** The resource owner will receive your request and can approve or decline it. You'll be notified of their decision.

---

### 4.4 Resource Detail Page

Select any resource card to view its full details, including:

- Item title, category, and condition
- Detailed description
- Owner information and location
- Availability status
- Lending type (Borrowing or Donation)

*[Screenshot: Resource Detail Page — Fig. 4.4]*

## 9. Troubleshooting & FAQ

### I can't log in.

Double-check your email and password. If you've forgotten your password, use **Forgot Password?** on the login modal (section 2.3). If your account has been deactivated, contact an administrator.

### I don't see the "Share Resource" or "Post Job" button.

You must be logged in to access these features. If you're logged in but still don't see them, your account may have restricted permissions. Contact an administrator.

### I can't borrow a resource.

Make sure you're logged in and that the resource status shows as "Available." If the resource is already marked as "Borrowed," it's currently out on loan.

### How do I contact the resource owner or job poster?

Contact information is displayed on the resource or job detail page. You can reach out via phone or the contact method provided.

### Can I edit my resource listing or job post?

Currently, you can manage your listings through the Dashboard. Contact an administrator if you need to make changes to a posted listing.

### How do reviews work?

After a borrow transaction or job is completed, you can leave a 1-5 star rating and a written comment for the other party. Reviews help build trust in the community.

### I want to become an Admin.

Admin accounts are assigned by existing administrators. Contact the current platform admin to request elevated access.
